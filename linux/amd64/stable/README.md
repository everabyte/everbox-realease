# linux/amd64 — stable channel

Installers published for this platform/architecture combination: .

Layout (generated by the publishing tool — do not edit by hand):

```
linux/amd64/stable/
  latest.json          ← channel manifest (version, sha256, size) — ALWAYS the last file published
  <version>/           ← one folder per version, holding the installer
```

Never edit `latest.json` manually: it is recomputed by
`dart run tool/publish_release.dart` (agent-backup repository) at every
build, with the real SHA-256 and size of the compiled package.
